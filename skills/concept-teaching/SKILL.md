# 概念精讲·费曼式

当用户说「给我讲讲 X」「我不懂 Y」「X 是什么意思」等，需要把一个概念/知识点讲透时使用。

## 步骤

1. **摸底**：先 `search_memory` 查这个用户的水平、背景与讲解偏好（喜欢深还是浅、要不要类比/代码），据此调整讲解深浅。**查不到就按「零基础入门」讲**，不要停下来发问——本技能在一轮内自主跑完，抛出去的问题等不到回答。若确有必须由用户拍板的信息，按合理默认推进并在答复末尾说明所用假设，请用户自行纠正。
2. **取材 grounding**：`search_knowledge` 查知识库里有没有相关资料——有就以资料为准讲解并标注来源，避免编造；没有再凭通识讲。（查资料用 `search_knowledge`，`search_memory` 里只有你记下的偏好结论，没有资料文档。）
3. **费曼式讲透**：按「一句话本质 → 类比/生活例子 → 拆解原理 → 常见误区/易错点」的层次讲，用最简语言，宁可多举例。涉及代码/计算的，用 `run_python` 等在沙箱跑个最小例子边跑边讲。
4. **即时小测**：讲完出 2～3 道题当场检验理解——`sample_questions(count)` 从题库抽相关题，或 `add_questions(questions=[...])` 现编（带 explanation）入库。答错的用 `save_wrong_answer` 沉淀（题库题传 `question_id`，即席题传 `stem`+`answer`+`user_answer`）。
5. **沉淀**：`remember` 记稳定的薄弱点/偏好（如「用户对递归还不熟」「讲解要配代码」）；**用户已明确要求**存档或要文件时，才 `save_to_knowledge` 存入知识库、或 `save_download` 导出笔记（文件名用 `.md`，本系统不能生成 PDF/Word）。没提就别顺手产出他没要的东西，也不要为此反问。

## 注意
- 目标是让用户「能自己讲出来」，不是把定义念一遍——多用「为什么是这样」设问，但要**自问自答**把道理讲透，别抛给用户等他回答。
- 有知识库资料时以资料为准并标来源，别凭空编（资料检索用 `search_knowledge`）。
- `remember` 只记跨会话有用的稳定结论，写前可先 `search_memory` 看是否已记过。
