# 联网调研·查完就能学

当用户说「帮我搞懂最新的 X」「查一下 Y 是什么」「最近 Z 有什么进展」等需要**最新/外部信息**时使用。目标不止是查到，而是让查到的内容变成可复习、可测的学材。

## 步骤

1. **查**：优先用联网搜索工具（web 搜索类）使用不同的关键词广度检索最新资料；非必要不用`browse`、`http_request`等工具读具体网页。
2. **核与整**：把多来源信息综合成一份**有条理的说明**（背景 → 关键点 → 现状/结论），标注信息来源，冲突处点出分歧，不确定的说明不确定。
3. **讲**：用最简语言把调研结论讲给用户，突出「和你相关的部分」。
4. **入库**：`save_to_knowledge(title, text)` 把整理后的调研笔记存入知识库，日后可检索复用。
5. **出题固化**：`generate_questions(topic=主题)` 就这份新知识库内容出几道题入库，或 `add_questions` 现编，帮用户把「读过」变「记住」。
6. **导出（可选）**：**用户明确要文件时**才 `save_download` 导出调研报告/笔记（文件名用 `.md`，本系统不能生成 PDF/Word）；只是想看结论就直接写在答复里，别顺手产出他没要的文件，也不要为此反问。

## 注意
- 时效性内容必须联网，别用可能过时的记忆硬答；信息带上来源。
- 多来源交叉核对，冲突与不确定要如实说明，不要编造。
- 联网抓取失败/被拦时，换搜索工具或换源，别卡在一个 URL 上。
