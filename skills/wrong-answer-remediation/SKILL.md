# 错题精讲·举一反三

当用户说「讲讲我的错题」「我哪里薄弱」「针对错题再练几道」等，需要从错题里定位薄弱点并针对性补强时使用本技能。

## 步骤

1. **取错题**：调用 `sample_wrong_answers(count)`（用户说了数量就照办，没说就取 5～10 道，别为此反问）。返回每条为 `{id, snapshot:{type,stem,options,answer,explanation}}`。若返回「错题集为空」，就在答复里说明错题集还是空的、建议先做题或考试积累错题——这是终局答复，不是等用户回话。
2. **归因聚类**：把错题按知识点或易错类型分组（如「概念混淆」「计算失误」「审题不清」「记忆性遗漏」），点出每组的**共性根因**，而不是逐题孤立地看。
3. **逐题精讲**：对每道错题——复述题目 → 给正确答案并讲清「为什么是它」→ 分析用户**最可能踩的坑**（结合错题快照里的信息）→ 用类比、最简语言把底层概念讲透。可先用 `search_memory` 查用户的水平/讲解偏好，调整深浅。
4. **举一反三**：针对薄弱知识点生成**相似练习题**（换情境/数字/表述，考同一知识点，别照抄原题）：
   - 该知识点在知识库有资料 → 用 `generate_questions(topic=知识点)` 从知识库出题并自动入题库；
   - 否则用 `add_questions(questions=[...])` 把你现编的相似题（带 explanation）整理入题库（与题库已有题自动去重）。
   - 注意：`generate_questions` **不去重**，同一主题反复调用会往题库堆重复题。同一知识点出过题就别再对它调一次。

   两个工具的返回末尾都带 `〔题目ID:id,id〕` 机读标记，即这批新题的 id（按出题顺序）。**记住这批 id**：用户接着说「就考刚才这几道」时，用 `start_exam(source="ids", question_ids=[...])` 精确开考——不要用 `source="bank"`，那是全库随机抽，考的不是刚出的这批。
5. **沉淀**：
   - 用 `remember` 记录**稳定、跨会话有用**的薄弱点（如「用户常混淆 X 与 Y」），便于以后个性化；
   - 用户明确要存档或要文件时，才用 `save_to_knowledge` 把精讲笔记存入知识库，或 `save_download` 导出一份复习提纲文件（文件名用 `.md`，本系统不能生成 PDF/Word）。
6. **当场小测（可选）**：直接在对话里出 2～3 道刚讲的相似题让用户即练；答错的用 `save_wrong_answer` 沉淀（题库题传 `question_id`，即席题传 `stem`+`answer`+`user_answer`）。
   **若你走的是 `start_exam` 开考**，判分与「答错自动入错题集」由系统在后台完成，此时**不要**再调 `save_wrong_answer`，否则同一道错题会重复入集。

## 注意
- 讲解要针对「**这个用户为什么错**」，不是复述一遍标准答案。
- 举一反三的题必须换壳考同一知识点，避免与原题雷同。
- 入库统一走 `add_questions`/`generate_questions`，不要用别的方式塞题。其中只有 `add_questions` 与题库已有题去重；`generate_questions` 不去重，别对同一主题反复调用。
- `remember` 只记稳定结论，别记一次性内容；写记忆前可先 `search_memory` 看是否已记录过。
