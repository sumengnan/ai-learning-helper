# 模拟考试主持

当用户说「考考我」「来一套模拟考试」「用错题集重考」等，需要一场有作答、判分、沉淀的正式测验时使用本技能。

## 步骤

1. **定范围**：先问清（若用户没说全）——考多少题、题型（single/multiple/truefalse/short 或不限）、题源。
2. **开考**：统一用 `start_exam(source=..., mode=...)`，判分与错题入库由系统托管。按题源选 `source`：
   - **用户指名要考某几道题**（「刚才生成的那 5 道」「就考这几题」）→ `source="ids"`，`question_ids` 传那批题的 id，按传入顺序出题。**绝不能用 `source="bank"` 顶替**——那是全库随机抽，考出来的不是用户要的那几道。
   - 从题库随机测验 → `source="bank"`，配 `count`/`types`。
   - 用错题集重考 → `source="wrong"`。
   - 题不在题库、你现编 → `source="adhoc"`，`questions` 传题目（含答案）。
   `mode`：`instant` 即时式（每题即判即讲）、`graded` 打分式（全部答完再公布）。
   若返回「题库为空 / 错题集为空」，按提示引导用户先去「题库」生成题目或先做题积累错题，不要自己硬编整套试卷冒充其题库。

   **题目 id 从哪来**：`add_questions`／`generate_questions` 的返回末尾带 `〔题目ID:id,id〕` 标记，就是那批题的 id（按出题顺序）；也可用 `list_questions` 查。所以「先出题、再考刚才那批」时，直接把上一步标记里的 id 传给 `start_exam(source="ids")` 即可。
3. **逐题呈现**：`start_exam` 会把第一题一并返回给你，**原样呈现**给用户，一次只出一题。用户作答后，系统自动判分并给出下一题，你照样原样呈现。**作答完成前绝不透露任何答案或解析**（打分式考试铁律）。
4. **判分与错题入库由系统托管**：开考后每题的判分、「答错自动入错题集」都由系统在后台确定性完成——你**无需也不要**再调用 `save_wrong_answer`，也不要自己比对答案。你只负责呈现题目，并在系统给出判定后按其结论讲解。
5. **讲评**：即时式下每题判定后就近讲解；打分式下系统在最后一题判完时给出成绩单（总分/正确率、逐题对错）——据此讲评每道错在哪、涉及的知识点，并给下一步建议（例如「X、Y 两个知识点较弱，建议用 wrong-answer-remediation 精讲并举一反三」）。
6. **收尾**：`unload_skill("exam-proctor")` 释放上下文。

## 注意
- 打分式考试第一铁律：作答完成前，不泄露答案、不剧透、不暗示对错。
- 一次一题、等待作答，不要把整卷一次性倒给用户。
- 用户指名「考刚才那几道」时必须走 `start_exam(source="ids")`；退回 `source="bank"` 会变成全库随机抽，是明确的错误。
- 开考后不要再调 `save_wrong_answer`：系统已自动沉淀错题，重复调用会造成错题集重复。
- `save_wrong_answer` 只用于**非 `start_exam`** 的即席小测（如精讲后随口考两道）：即席题必须传 `stem` 与 `answer`，题库题可只传 `question_id`。
