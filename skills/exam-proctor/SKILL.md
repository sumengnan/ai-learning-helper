# 模拟考试主持

当用户说「考考我」「来一套模拟考试」「用错题集重考」等，需要一场有作答、判分、沉淀的正式测验时使用本技能。

## 步骤

1. **定范围**：先问清（若用户没说全）——考多少题、题型（single/multiple/truefalse/short 或不限）、题源：
   - 从题库正式测验 → 用 `sample_questions(count, types)`；
   - 用错题集重考 → 用 `sample_wrong_answers(count)`。
   两个工具返回的题目都**含答案与解析，仅供你出题与判分**。
2. **抽题**：调用对应工具取题。若返回「题库为空 / 错题集为空」，按提示引导用户先去「题库」生成题目或先做题积累错题，不要自己硬编整套试卷冒充其题库。
3. **逐题呈现**：一次只出一题——题干 + 选项（选择题用 A/B/C/D 标号）。等用户作答后再出下一题。**作答完成前绝不透露任何答案或解析**（打分式考试铁律）。
4. **判分**：全部作答后逐题对照正确答案：
   - single 比选项索引；multiple 比索引集合（多选少选都算错）；truefalse 比真假；
   - short（简答）抓要点、语义等价即算对，可参考该题 explanation，不必逐字一致。
5. **错题入库**：正式题库测验中每道**答错**的题调用 `save_wrong_answer`：
   - 题库题优先只传该题的 `question_id`（`sample_questions` 返回里带），让系统取快照；
   - 一并传用户的 `user_answer`。
   - 注意：**用错题集重考的题答错不必再存**（本就在错题集里），避免重复。
6. **成绩单**：给出总分/正确率、逐题对错清单、每道错在哪、涉及的知识点，以及下一步建议（例如「X、Y 两个知识点较弱，建议用 wrong-answer-remediation 精讲并举一反三」）。
7. **收尾**：`unload_skill("exam-proctor")` 释放上下文。

## 注意
- 打分式考试第一铁律：作答完成前，不泄露答案、不剧透、不暗示对错。
- 一次一题、等待作答，不要把整卷一次性倒给用户。
- 判简答题看要点与语义等价，别做逐字匹配。
- `save_wrong_answer`：题库题传 `question_id` 让系统取快照；即席题（不在题库）必须传 `stem` 与 `answer`。
