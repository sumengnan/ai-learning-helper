# 间隔重复复习

当用户说「今天该复习什么」「帮我安排复习」「好久没看的知识点」时使用，按遗忘规律挑出「该复习的」内容，即测即巩固。

## 步骤

1. **回看学过的**：`recall_episodes` 检索过往的学习经历（学过/考过/错过什么），`search_memory` 查已记录的知识点掌握度与薄弱点，还原「这个用户学过哪些、什么时候学的」。
2. **挑复习对象**：按「越久没碰、当时越薄弱、越容易忘」优先，选出今天该复习的 3～5 个知识点或一批错题。跟用户确认要复习哪些。
3. **组卷即测**：
   - 错题回顾 → `sample_wrong_answers(count)` 取出旧错题重做；
   - 知识点巩固 → `sample_questions(count)` 抽题，或 `generate_questions(topic=...)` 就该点出新题。
4. **即测与讲评**：让用户做，逐题讲评。**这次又错的**要重点讲，并 `save_wrong_answer` 继续沉淀；**这次做对的**说明有进步。
5. **更新掌握度**：`remember` 更新掌握情况（如「递归已掌握，可降低复习频率」「XX 仍薄弱，下次再练」），让下次复习挑得更准。
6. **收尾**：`unload_skill("spaced-review")` 释放上下文，并给出「下次建议 X 天后再复习 Y」的节奏提示。

## 注意
- 复习的核心是**挑对内容**：优先久未复习 + 当时薄弱的，别平均用力。
- 每轮都要更新 `remember` 里的掌握度，否则下次还挑一样的、就失去间隔重复的意义。
- 又错的题一定要 `save_wrong_answer` 留下，别让它溜走。
